# 家账 · Household Finance

[Open the application](https://geekerding.github.io/household-finance/)

This repository contains only the compiled, empty application and a labeled synthetic demo. No personal bank statements, vault backups, screenshots or household records are published.

Financial data is encrypted in each browser. This website does not provide cross-device data synchronisation. The local household center uses an encrypted Mac service and a separately paired private Tailscale PWA; that profile is never published here. To move legacy browser records, export and restore an encrypted backup. Keep the password and backup safe.

Amazon Visa supports the Openbank amount/points table. Review statement totals and unsupported layouts before importing.
